# GeoDrill Pro — audited software delivery through Module 17

Version 0.8.0 extends the preserved Modules 1–11 with six offline research workflows. The acceptance target is the audited MVP/research software scope in audit/part-1.md, sections 5.12–5.17. It is not the original proposal's unsupported full-autonomy, virtual-sensing, exact-life or field-performance claims.

| Module | Delivered workflow | Evidence and boundary |
|---|---|---|
| M1–M11 | Existing geometry, casing, log clustering, shaly-sand, external EM review, laminar hydraulics, stability, transport, surge/swab, MSE/torque/drag and buckling | Preserved prior acceptance records in MODULES-1-10.md and MODULES-1-11.md; 406-test full regression suite passed |
| M12 | Straight-segment coupled axial/torsional/lateral simulation; separate native acceleration review | Immutable geometry, hole/installed-casing clearance, modal eigenproblem, nonlinear clearance spring, response refinement, energy balance. Native samples retain quality, timing and units. Bandwidth eligibility does not establish observability; no virtual vibration diagnosis |
| M13 | Bit identity, recovered inspections, evidence availability, formation/family cohort and run comparison | Confirmed failures need recovered inspection evidence; planned trips/ongoing observations are censored; future receipt excluded. Descriptive Kaplan–Meier and conditional costs do not authorize trips or predict an individual remaining life |
| M14 | Casing-bound contact exposure, material-specific wear, separate fatigue, inspection residual and restricted wall-strength scenario | Coefficient convention m²/N, uncertainty corner, log–log S–N interpolation without extrapolation, Miner accounting. Localized grooves, missing exposure, exhausted wall and missing properties withhold the capacity screen |
| M15 | Native flow/contained-mass trends, causal control-volume residuals and offline candidate/event replay | Adjacent native intervals only; signed transfers, missing/negative/gap/state gates, persistence reset, all missed/unmatched candidates retained. Replay metrics do not establish early-kick or well-control performance |
| M16 | Reviewed external mud/gas phase records and prescribed-boundary closed-batch replay; extra characterized nonpolar binary EOS research | Original study document, model version/reference, supplied convergence/stability/balance flags, composition checks, conservation and refinement. Native binary PR is not drilling-mud solubility; no coupled wellbore momentum/energy/slip solver |
| M17 | Isolated pressure-plant/PID simulation and independent simulated request validation | Exact configuration hash, target/unit allowlist, logical lease, expiry, duplicate/rate/slew checks, process envelope, interlocks, disconnect, unknown state and manual override. Faults invalidate pending requests. No network adapter or equipment-command route |

Each new module has a typed input editor, SI JSON export/import, plots or record tables, saved-study reopening, explicit assessment statuses, geometry/survey hashes and report preservation. Large record lists retain all values while showing the first 24 editable records. Import stores original bytes and SHA-256 plus a canonical document in Parquet; calculation results state whether subsequent inputs match that document.

## Qualification still required for field use

No qualified instrumented BHA dataset, independently calibrated bit cohort, material/fluid wear programme, adjudicated field anomaly corpus, actual-mud PVT/flow-loop data or OEM/HIL facility was supplied. Those are production qualification gates, not proof supplied by a successful software test. The detailed coupled structural, operational prediction and live-control programmes remain outside this offline release.

Actual supervisory rig integration is excluded by the audit. M17 provides the explicitly permitted software/model-in-the-loop research environment only. The application retains equipment_control=false and equipment_authority=none.

Existing historical snapshots retain their original application version and hashes. This release does not rewrite earlier reports.
